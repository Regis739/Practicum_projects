# Задача

В этом проекте мы создали модель, способную предсказать, тип операций на сердце, необходимых определенному ребенку.

# Итоги

Наша лучшая модель — модель CatBoost. Оценка f1 macro, полученная для перекрестной проверки, составляет 78,3%, а для тестового набора данных — 79,4%.
